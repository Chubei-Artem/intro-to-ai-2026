# Лабораторна робота №2: Моделювання нейронних мереж (Перцептрон, Хопфілд, Хеммінг)

Реалізація класичних архітектур нейронних мереж для розпізнавання та відновлення графічних образів за допомогою фреймворку Streamlit.

## Реалізовані модулі

1. **Перцептрон Розенблата (2 класи):**
   * Класифікація класів «0» та «1» на основі нормованих ознакових векторів сітки $5 \times 5$.
   * Навчання з учителем із покроковою корекцією вагових коефіцієнтів та зсуву ($b$).
   * Графік збіжності помилок за епохами та відображення вектора синаптичних ваг.

2. **Мережа Хопфілда (3 класи):**
   * Автоасоціативна пам'ять для еталонів «0», «1», «2».
   * Побудова симетричної матриці зв'язків $W$ розміром $25 \times 25$ за правилом Хебба.
   * Асинхронна процедура релаксації для відновлення зашумлених біполярних образів.

3. **Мережа Хеммінга (3 класи):**
   * Перший шар розрахунку відстаней Хеммінга за ваговими коефіцієнтами $w_{ik} = x_i^k / 2$ та порогами $b_k = n / 2$.
   * Другий динамічний шар (MAXNET) із взаємним латеральним гальмуванням нейронів (принцип «переможець отримує все»).
   * Візуалізація динаміки пригнічення сигналів у часі.

## Запуск

1. Встановіть бібліотеки:
   ```bash
   pip install -r requirements.txt
   streamlit run app.py
   ```
