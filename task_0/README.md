# Lab 1 - Image Uploader (Streamlit)

Ця лабораторна робота реалізує завантажувач зображень форматів `.jpg`, `.jpeg`, `.png`, `.webp` та їх візуалізацію. Реалізовано як базовий варіант за допомогою **Streamlit**.

## Структура файлів

* `app.py` — базова версія інтерфейсу на Streamlit із кастомним оформленням фону.
* `requirements.txt` — перелік необхідних бібліотек для роботи застосунку.
* `results.pdf` — звіт із демонстрацією роботи та скріншотами.

## Інструкція із запуску

### Streamlit
Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   streamlit run app.py
