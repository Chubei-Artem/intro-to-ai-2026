Ефективність навчання глибоких мереж критично залежить від алгоритму оптимізації. Класичний стохастичний градієнтний спуск (SGD) використовує єдину фіксовану швидкість навчання (learning rate) для всіх параметрів. Натомість адаптивний оптимізатор Adam (Adaptive Moment Estimation) обчислює експоненційно зважені ковзні середні першого моменту (середнє градієнтів, параметр beta_1 = 0.9) та другого моменту (нецентрована дисперсія градієнтів, параметр beta_2 = 0.999). Стандартне початкове значення швидкості навчання для Adam становить lr = 0.001, що забезпечує швидку збіжність на початкових етапах тренування.
