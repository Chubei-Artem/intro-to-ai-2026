# Лабораторна робота №1: Адаптивна система розпізнавання та кластеризації

Система розпізнавання графічних бінарних образів на основі простору числових ознак (сітковий метод), розроблена на базі бібліотеки Streamlit.

## Функціонал програми

1. **Побудова векторів ознак:**
   * Розбиття поля зображення регулярною сіткою $N \times N$ (за замовчуванням $5 \times 5$).
   * Розрахунок абсолютного вектора ознак (кількість пікселів об'єкта в кожній зоні).
   * Нормування вектора ознак відносно загальної площі об'єкта.
   * Підтримка як темних ліній на світлому тлі, так і світлих ліній на темному тлі (інверсія).

2. **Класифікація за методом порівняння з еталоном:**
   * Відображення еталонів класів (цифри «0», «1», «2», «3») з виведенням як абсолютних, так і нормованих векторів.
   * Розрахунок відстаней до кожного еталона за вибором: Евклідова, Манхеттенська або норма Чебишева.
   * Ідентифікація класу за критерієм мінімальної відстані.

3. **Кластеризація та статистична обробка:**
   * Навчання системи на вибірках спотворених/зашумлених зразків для кожного класу.
   * **Варіант 1:** Розрахунок геометричних центрів кластерів (математичне сподівання векторів) та класифікація за центрами.
   * **Варіант 2:** Метод ортогональних областей (обчислення гіперпрямокутника $[\min, \max]$ для кожної компоненти) та перевірка належності образу до області.

## Інструкція із запуску

1. Встановіть необхідні залежності:
   ```bash
   pip install -r requirements.txt
   streamlit run app.py
   ```
